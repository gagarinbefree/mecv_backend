# MECV backend

[![Tests and build](https://github.com/gagarinbefree/mecv_backend/actions/workflows/ci.yml/badge.svg?branch=main)](https://github.com/gagarinbefree/mecv_backend/actions/workflows/ci.yml)

Backend цифровой визитки на TypeScript, NestJS, Prisma и Apollo GraphQL.

Сейчас подготовлен начальный каркас: функциональная композиция NestJS, строгая типизация, ESLint, тесты и сборка. Профиль, Prisma-схема и GraphQL API будут реализованы следующими TDD-этапами. Docker отложен; для работы с данными используется обычный PostgreSQL.

Контракт запроса profile и связанных типов описан в [GraphQL-схеме](src/profile/profile.graphql). Тесты проверяют запрос из задания, вложенные данные, пустые списки и допустимость null. GraphQL Code Generator создаёт из SDL типы данных и резолверов. Подключение схемы к HTTP-серверу и обработка скаляра Date относятся к следующим этапам.

Плашка отражает фактический результат workflow Tests and build в GitHub Actions. Зелёный статус означает, что генерация типов, ESLint, проверка типов, тесты и сборка завершились успешно; отсутствие запусков не является подтверждением успеха.

## Локальная проверка

Нужен Node.js 24.15 или совместимый более новый patch ветки 24.

~~~shell
npm ci
npm run check
~~~

Отдельные команды: npm run lint, npm run typecheck, npm test и npm run build. Каждая автоматически обновляет сгенерированные типы перед запуском. Сборка помещает JavaScript в dist. На текущем этапе сервер приложения ещё не реализован.

## Типы GraphQL

Настройки находятся в [codegen.ts](codegen.ts). Источник типов — SDL; результат записывается в src/generated/graphql.ts, исключён из Git и не редактируется вручную. Для отдельного обновления выполни npm run codegen.

Типы данных и списки неизменяемы. Nullable-поля представлены через null; свойства данных не получают дополнительный undefined. Date явно сопоставлен со string на входе и выходе. Это описание TypeScript-контракта; проверка формата YYYY-MM-DD будет реализована в обработчике скаляра. Новый скаляр без явного сопоставления останавливает генерацию.

Типы функций резолверов включают parent, args, context, info и результат. Сейчас поля схемы не принимают аргументов, поэтому args — Record<PropertyKey, never>. [Контекст запроса](src/graphql/graphql-context.ts) пока представляет неизменяемый словарь unknown без сервисов и загрузчиков; перед использованием неизвестное значение требует проверки. При подключении данных контекст получит конкретные зависимости запроса.

Команда npm test запускает обычные тесты и отдельные проверки типов через TypeScript. Они проверяют даты, nullability, неизменяемость данных и сигнатуры резолверов. npm run test:watch обновляет типы при старте; после изменения SDL перезапусти эту команду.

## Правила разработки

TDD, функциональный стиль без собственных классов, содержательный JSDoc у каждой функции, строгий TypeScript без any. Эти правила распространяются на тесты и проверяются ESLint. Отрицательные тесты отдельно подтверждают запрет классов, any и функций без JSDoc.
